Entry for the [make.fun news-image-20261125 competition](https://make.fun/c/news-image-20261125):
one 1024×1024 front page summing up the world news of Wednesday 25 November 2026.

The page carries 50 sourced stories in section panels, a six-slot UTC timeline,
a date-check line and a By the Numbers box. `src/frontpage.html` is the page source;
it was rendered to `entry.png`, and `main.ts` (Node 22) copies that image to the output.
